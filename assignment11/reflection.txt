1. Reflect on the differences between static and interactive visualizations.

Static visualizations, such as bar charts and line plots provide a fixed view of 
the data.They are useful for simple analysis, reporting, and situations where the
audience only needs to understand a single perspective of the dataset. However, they do not 
allow users to explore the data further or interact with it beyond what is displayed.

In contrast, interactive visualizations allow users to engage with the data dynamically. Users can hover over 
points, zoom into specific regions, filter categories, and explore patterns in real time. This makes it 
easier to uncover deeper insights that may not be immediately visible in static charts.


2. Write a short paragraph discussing the advantages of using dashboards for real-time data exploration.

Dashboards built with interactive tools are especially powerful for real-time data exploration because 
they bring multiple visualizations together in one place and allow users to interact with live or frequently 
updated data. This helps decision-makers quickly identify trends, compare metrics, and respond to changes 
without needing to manually reprocess or replot data.

3. Explain how interactive tools like Plotly can improve data communication in professional settings.

In professional settings, interactive tools like Plotly improve data communication by making complex 
datasets more accessible and intuitive. Instead of relying on static reports, stakeholders can explore
the data themselves, which leads to better understanding, faster insights, and more informed decisions. These tools also make presentations more engaging and help bridge the gap between technical and non-technical audiences.
